Preliminaries

This vignette illustrates the use of the normal_block() function and the methods accompanying its R6 classes.

From a statistical point of view, the normal_block() function fits a multivariate Normal-Block model (a Gaussian graphical model with a latent clustering structure) to a table of observations, possibly after correcting for the effect of covariates. Depending on the arguments given, the function uses a clustering supplied by the user or infers one, includes zero-inflation or not, infers a sparse network or not, and so on. Parameter inference can either be done with an integrated variational Expectation-Maximization approach (recommended) or with a faster heuristic approach.

This vignette covers the default family, where the clustering structures the covariance of the variables (model = "var"). A complementary family clusters variables by their response to covariates instead (model = "mean"); see vignette("mean-block-breast-cancer").

Theoretical explanations for this model and full estimation details (criteria, E/M updates) can be found in Tous and Chiquet (2026).

Requirements

library(normalblockr)
library(pheatmap)
library(paletteer)

Data simulation

We illustrate the analysis with two simulated datasets.

Fix the seed to make the results reproducible.

set.seed(1)

Data are simulated with generate_normal_block_var_data().

Fix simulation parameters

Several parameters need to be defined to simulate the data:

n = 100 # Number of samples (number of rows in the matrix of observations)
p = 40  # Number of entities observed (number of columns in the matrix of observations)
d = 2   # Number of covariates
q = 6   # Number of clusters
kappa = 0 # Mean zero-inflation probability (can also be a vector to define one ZI-probability for each variable). kappa = 0 means that there is no zero-inflation.
omega_structure = "erdos-renyi" # Network structure.
u_v = c(0.3, 0.1) # Parameters to generate an association matrix from a graph, details given in the bibliography.
SNR = 0.75 # Signal to Noise Ratio, defines the relative weight of the covariates and the variance
alpha = rep(1/q, q) # Vector giving probabilities of belonging to each cluster
range_X = c(0, 10)  # Min and max values for the covariates
range_D = c(0.5, 1.5) # Min and max values for the individual entities variances

Simulation 1 (no zero-inflation)

generate_normal_block_var_data() generates data under the Normal-Block model. It returns a list containing the simulated covariates \(X\) and observations \(Y\), and the simulation parameters (including the clustering \(C\)).

my_nb_data <- generate_normal_block_var_data(n, p, d, q, kappa, omega_structure, u_v,
                                            SNR, alpha, range_X, range_D)
pheatmap::pheatmap(my_nb_data$Y,
                   color =paletteer::paletteer_c("ggthemes::Orange-Gold", n = 100), cluster_rows = FALSE, cluster_cols = FALSE, show_rownames = FALSE)

Simulation 2 (with zero-inflation)

To generate zero-inflated data, we set-up kappa as a vector of zero-inflation probabilities. One needs to ensure that these values are between 0 and 1.

kappa_zi <- rnorm(p, mean = 0.7, sd = 0.05)
kappa_zi <- unlist(lapply(kappa_zi, f <- function(x) return(max(0, min(x, 0.9)))))
my_nb_data_zi <- generate_normal_block_var_data(n = n, p = p, d = d, q = 5, kappa = kappa_zi,
                                                omega_structure = omega_structure, u_v = u_v,
                                                SNR = SNR, alpha = rep(1/5, 5),
                                                range_X = range_X, range_D = range_D)

For a better visualization of the zero-inflated data, we set-up the 0 to be shown in white.

min_val <- min(my_nb_data_zi$Y) ; max_val <- max(my_nb_data_zi$Y)
orange_gold_pal <- paletteer::paletteer_c("ggthemes::Orange-Gold", n = 100)
n_breaks <- 100
zero_pos <- round((0 - min_val) / (max_val - min_val) * n_breaks) + 1
custom_pal <- c(orange_gold_pal[1:(zero_pos - 1)], "white", orange_gold_pal[zero_pos:n_breaks])
pheatmap::pheatmap(my_nb_data_zi$Y,
                   color = custom_pal,
                   cluster_rows = FALSE, cluster_cols = FALSE,
                   show_rownames = FALSE)

Prepare the data for a Normal-Block analysis

A specific data object of class NormalBlockData needs to be created to analyse the data with normalblockr.

One can use \(Y\) and \(X\) alone to create the NormalBlockData object.

my_data    <- NormalBlockData$new(my_nb_data$Y, my_nb_data$X)
my_data_zi <- NormalBlockData$new(my_nb_data_zi$Y, my_nb_data_zi$X)

Alternatively, if one only wants to include some of the covariates contained in \(X\), a formula can be used to specify which one:

colnames(my_data$X) <- c("X1", "X2")
my_data_alt    <- NormalBlockData$new(my_data$Y, my_data$X, formula = ~ 0 + X1)

Run a Normal-Block analysis

All Normal-Block analyses are run with the normal_block() function, called with different arguments depending on whether the clustering (or the number of clusters) is known, and on the requested level of sparsity, among other factors. See ?normal_block for full details.

By default, the parameters are inferred using a variational Expectation-Maximization approach, with up to 500 iterations. Finer control of the optimization is possible through the control argument of normal_block(), a list generated by NB_control().

With non-zero-inflated data

Fixed clustering

When the variables’ clustering is known, it can be given directly as an input to normal_block().

my_NB <- normal_block(data = my_data,
                      blocks = my_nb_data$parameters$C)
#> Fitting a diagonal normal-block-var model with fixed clusters 
#> 
#> DONE

Convergence of the model can be checked with plot().

plot(my_NB)

Fixed number of clusters

When the variables’ clustering is unknown, the number of clusters can simply be fixed via the blocks argument.

my_NB <- normal_block(data = my_data,
                      blocks = q)

#> 
#> DONE
print(my_NB)

#>  niter

aricode::ARI(my_NB$clustering, apply(my_nb_data$parameters$C, 1, which.max))

Unknown number of clusters

When the number of clusters is unknown, normal_block() can be given a range of candidate values instead, returning a collection of Normal-Block models, one per number of clusters.

my_NB_unknown <- normal_block(data = my_data,
                              blocks = 2:8)
#> Fitting a collection of diagonal normal-block-var models over q 
#>   refine(): improved 6 of 7 models
#> 
#> DONE

Each model of the collection is first fitted from its own initial clustering (a \(k\)-means on the residuals, see NB_control()), then the whole collection is polished by refine(): for every \(q\), it tries to split a cluster of the model with \(q-1\) clusters and to merge two clusters of the model with \(q+1\), and keeps a candidate when it lowers the deviance. Since the models are nested, a deviance that increases with \(q\) signals a poor local optimum: print() reports such cases (deviance_violations).

my_NB_unknown
#> A collection of diagonal normal-block-var models over q 
#> ===========================================================================
#>   7 model(s) explored
#>     q ranging from 2 to 8 
#> ===========================================================================
#> * Useful fields
#>     $models, $criteria
#> * Useful methods
#>     print(), summary(), plot(), $get_best_model()
#> * Warning: the deviance increases with q at q = 8 
#>     (nested models: a sign of poor local optima that refine() did not repair).

Here, a violation remains at q = 8, at the edge of the explored range, where refine() can only seed the model from its smaller neighbour; it does not affect the selected model.

A specific model can be selected either by its number of clusters or as the best model for a given criterion (BIC, ICL or EBIC). The value of each criterion, for every model in the collection, can be visualized with plot().

plot(my_NB_unknown)

Model selection is done with get_model() when a specific number of clusters is required, and with get_best_model() to select the best model for a given criterion.

myNB_6   <- my_NB_unknown$get_model(6)
myNB_BIC <- my_NB_unknown$get_best_model("BIC")
myNB_BIC$q
#> [1] 6

The criteria above rest on penalties. Cross-validation offers a penalty-free alternative: normal_block_cv() fits the collection on all folds but one and computes the exact log-likelihood of the left-out observations (for the variance-block model, the marginal over the latent factors, computed at the selected partition). It typically plateaus beyond the true number of clusters, so the one-standard-error rule picks the smallest \(q\) within one standard error of the best.

set.seed(1)
my_NB_cv <- normal_block_cv(my_data, blocks = 2:8, folds = 5)
my_NB_cv
#> Cross-validated log-likelihood, 5 folds (larger is better)
#>  q    loglik       se
#>  2 -7411.376 82.94900
#>  3 -7078.996 73.31608
#>  4 -6776.621 64.99127
#>  5 -6564.980 50.40945
#>  6 -6496.787 49.52596
#>  7 -6502.774 49.36242
#>  8 -6503.653 49.38029
#> Best: q = 6 (one-standard-error rule; maximum at q = 6)
plot(my_NB_cv)

Here BIC, ICL and cross-validation all recover the 6 simulated clusters. By default the columns of \(Y\) are rescaled for the variance-block model, which usually helps on real data (see ?NormalBlockData).

Playing with sparsity

By default, no penalty is applied to the association network. A penalty can be added via the sparsity argument of normal_block(), with any of the parametrizations seen above (fixed clustering, fixed number of clusters, or unknown number of clusters). The examples below use the known clustering, so that the inferred network can be compared with the simulated one, which has 9 edges out of 15 possible ones.

To use a fixed \(\ell_1\) penalty (Tous and Chiquet 2026) on the network, pass that value to the sparsity argument. The larger the penalty, the sparser the network:

my_NB_sparse_low <- normal_block(data = my_data,
                                 blocks = my_nb_data$parameters$C,
                                 sparsity = 0.05,
                                 control = NB_control(verbose = FALSE))
my_NB_sparse_high <- normal_block(data = my_data,
                                  blocks = my_nb_data$parameters$C,
                                  sparsity = 0.2,
                                  control = NB_control(verbose = FALSE))
c(low = my_NB_sparse_low$n_edges, high = my_NB_sparse_high$n_edges)
#>  low high 
#>   12    7

It is usually hard to know a priori which penalty is best. normal_block() can instead explore a range of penalties by setting sparsity = TRUE, which returns a collection of Normal-Block models, one per penalty. The criteria can then be plotted as a function of the penalty, using plot().

my_NB_sparse <- normal_block(data = my_data,
                             blocks = my_nb_data$parameters$C,
                             sparsity = TRUE,
                             control = NB_control(verbose = FALSE))
plot(my_NB_sparse)

A penalty is selected as a number of clusters is, with get_model() and get_best_model(). The penalized criteria tend to favour weak penalties, hence dense networks. Stability selection (StARS) refits the path on subsamples of the observations, the clustering being held fixed, and keeps the smallest penalty whose network is stable enough; it is usually better suited to reading the network.

myNB_sparse_BIC   <- my_NB_sparse$get_best_model("BIC")
set.seed(1)
myNB_sparse_StARS <- my_NB_sparse$get_best_model("StARS")
c(BIC = myNB_sparse_BIC$n_edges, StARS = myNB_sparse_StARS$n_edges)
#>   BIC StARS 
#>    12     7

The edges selected by StARS can be compared with those of the simulated network:

true_net  <- my_nb_data$parameters$Omega != 0
stars_net <- as.matrix(myNB_sparse_StARS$latent_network("support")) != 0
table(simulated = true_net[upper.tri(true_net)], StARS = stars_net[upper.tri(stars_net)])
#>          StARS
#> simulated FALSE TRUE
#>     FALSE     5    1
#>     TRUE      3    6
myNB_sparse_StARS$plot_network(layout = igraph::layout_with_fr)

The penalty and the number of clusters can also vary jointly, by passing a range of values to blocks together with sparsity = TRUE. get_model(q) then returns the path of penalties for \(q\) clusters, from which a penalty is selected as above.

my_NB_sparse_unknown <- normal_block(data = my_data,
                                     blocks = 5:7,
                                     sparsity = TRUE,
                                     control = NB_control(verbose = FALSE))
my_NB_sparse_unknown$get_model(6)
#> A collection of diagonal normal-block-var models over sparsity penalties, with fixed q 
#> ===========================================================================
#>   30 model(s) explored
#>     sparsity ranging from 0.00458 to 0.458 
#> ===========================================================================
#> * Useful fields
#>     $models, $criteria
#> * Useful methods
#>     print(), summary(), plot(), $get_best_model()

With zero-inflated data

The process is similar with zero-inflated data, but zero_inflation = TRUE must be passed to normal_block(). The example below uses the simulated number of blocks and no penalty on the network. See vignette("zero-inflated-normal-block") for the model and a real-data example.

my_NB_zi <- normal_block(data = my_data_zi,
                         blocks = 5,
                         zero_inflation = TRUE)
#> Fitting a zero-inflated diagonal normal-block-var model with 5 unknown clusters 
#> 
#> DONE

When the data is zero-inflated, the inference process may take longer.

plot(my_NB_zi)

The clustering inference may also be harder.

aricode::ARI(my_NB_zi$clustering,
             apply(my_nb_data_zi$parameters$C, 1, which.max))
#> [1] 0.5816134
